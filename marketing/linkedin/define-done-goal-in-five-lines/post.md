"Fix the login bug" is not a goal for an AI agent.
Before I hand off a task, I write five lines: outcome, invariants, evidence, stop, done when.
Example: an expired session signs in and returns to the original page, while valid sessions behave exactly as before.
If you can't say what done looks like, the agent can't either.
