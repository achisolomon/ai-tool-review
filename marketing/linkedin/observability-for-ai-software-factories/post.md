Can you see what your agents are doing right now?
There is no single dashboard for it yet, so we assemble three layers: agent telemetry, delivery metrics, and a factory-floor view.
Claude Code exports OpenTelemetry with CLAUDE_CODE_ENABLE_TELEMETRY=1, and PR labels show what is blocked on a human.
We track tasks completed per dollar, first-pass acceptance, review wait, escalations and rework.
