The agent that wrote the code is the worst one to review it.
Let a creator build against the goal, then hand the diff to a verifier with a fresh context.
Verifier prompt: "Assume the implementation is wrong. Find the evidence."
Every handoff carries: result · evidence · open questions · next owner.
