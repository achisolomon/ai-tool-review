A restart is an action. Recovery is an outcome.
Our agents only move a step forward on evidence: errors and p99 back at baseline, not "I restarted it".
Every failure then ships a guard: contain, capture evidence, name the failure class, add a check.
Robust survives the shock; antifragile learns from it.
