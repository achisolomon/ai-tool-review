pgvector is a PostgreSQL extension that enables vector storage and similarity search within PostgreSQL databases.

## Key Features

- PostgreSQL vector data type
- Efficient similarity search (IVFFlat, HNSW)
- Integration with standard SQL
- Scalable indexing options
- Community-driven development

## Pricing

- Free: Open-source under PostgreSQL license

- New indexing algorithms and performance optimizations for large-scale vector operations
