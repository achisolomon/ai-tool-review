## Overview

<div class="overview">
<p>Exa is a web search API designed for AI agents and LLMs, using neural embeddings rather than keyword matching. Unlike traditional search engines, Exa converts queries and indexed pages into high-dimensional vectors representing semantic meaning. The platform offers multiple search modes from sub-150ms instant search for chatbots to 12-40 second deep-reasoning search for research agents. Exa powers search for Cursor, Cognition, HubSpot, OpenRouter, Monday.com, and over 400,000 developers. In May 2026, Exa raised $250M Series C at a $2.2B valuation.</p>
</div>
