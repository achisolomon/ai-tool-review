## Overview

<div class="overview">
<p>Nimbalyst is an open-source visual workspace designed for developers working with AI coding agents like Claude Code and Codex. It provides a desktop and mobile environment where users can manage agent sessions via a kanban board, visually edit multiple file types (markdown, CSV, diagrams, mockups), and track tasks with integrated project management. The platform emphasizes parallel session management with git worktree isolation, allowing developers to run multiple agents simultaneously while maintaining organized workflows. Trusted by users at companies including Automattic, Redfin, Vanta, Gainsight, and Zillow.</p>
</div>
