## Overview

<div class="overview">
<p>NanoClaw is a secure, lightweight alternative to OpenClaw designed for developers who need full control over their AI agent infrastructure. Built to run in containerized environments, it prioritizes security, transparency, and customization. The framework is intentionally minimalist, making it easier to understand, audit, and modify for specific use cases. Unlike larger agent frameworks, NanoClaw focuses on giving developers a clear, maintainable codebase they can adapt to their exact requirements while maintaining strong security boundaries through container isolation.</p>
</div>
