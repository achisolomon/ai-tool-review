## Overview

<div class="overview">
<p>Google ADK (Agent Development Kit) is an enterprise-focused open-source framework supporting Python, TypeScript, Go, Java, and Kotlin for building production-grade AI agents. It emphasizes developer productivity with comprehensive debugging tools, built-in observability, and patterns for reliable agent behavior at scale. The framework integrates seamlessly with Google Cloud services while remaining cloud-agnostic for flexible deployment.</p>
</div>
