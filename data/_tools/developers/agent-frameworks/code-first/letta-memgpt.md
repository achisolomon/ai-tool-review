## Overview

<div class="overview">
<p>Letta (formerly MemGPT) pioneered the concept of giving LLMs operating-system-like memory management, enabling agents to maintain context indefinitely. Born from Berkeley research, it creates stateful agents that remember everything, learn continuously from interactions, and improve their performance over time. The framework manages memory hierarchies automatically, moving information between working memory and long-term storage as needed for truly persistent agent intelligence.</p>
</div>
