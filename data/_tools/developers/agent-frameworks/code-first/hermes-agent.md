## Overview

<div class="overview">
<p>Hermes Agent from Nous Research represents a paradigm shift from ephemeral coding assistants to persistent, autonomous agents that live on your server. It continuously learns from interactions, builds long-term memory, and becomes more capable over time. Unlike traditional copilots, Hermes operates independently, maintaining context across sessions and evolving its capabilities through actual usage rather than just prompting.</p>
</div>
