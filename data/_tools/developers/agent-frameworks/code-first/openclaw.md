## Overview

<div class="overview">
<p>OpenClaw is a cross-platform AI coding agent designed to make AI-assisted development accessible across all major operating systems. It runs seamlessly on macOS, Linux, and Windows, with a streamlined one-liner installation that handles Node.js and all dependencies automatically. The platform offers both stable and development release channels, allowing users to choose between production-ready stability or cutting-edge features. OpenClaw focuses on providing developers with an intuitive AI coding companion that integrates naturally into their existing workflows, regardless of their operating system preference. The framework emphasizes ease of setup and consistent behavior across platforms.</p>
</div>
