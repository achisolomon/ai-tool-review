## Overview

<div class="overview">
<p>Semantic Kernel is Microsoft's lightweight, open-source SDK designed to help developers build AI agents and integrate the latest AI models into enterprise applications. It serves as efficient middleware that enables rapid delivery of enterprise-grade solutions with support for C#, Python, and Java. Microsoft and other Fortune 500 companies already leverage Semantic Kernel because it's flexible, modular, and observable, with built-in telemetry support and security-enhancing capabilities like hooks and filters for responsible AI solutions at scale.</p>
</div>
