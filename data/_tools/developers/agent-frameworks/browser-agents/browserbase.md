## Overview

<div class="overview">
<p>Browserbase provides serverless headless browser infrastructure purpose-built for AI agents and web automation. It offers managed Chromium instances with built-in stealth features, persistent sessions, live debugging, and APIs for search, fetch, and screenshots—making the web as reliable and programmable as APIs. Teams use Browserbase to run browser-based agents without managing infrastructure, proxies, or anti-bot bypasses, with pay-per-use pricing and enterprise-grade reliability.</p>
</div>
