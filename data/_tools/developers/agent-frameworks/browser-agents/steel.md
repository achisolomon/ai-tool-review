## Overview

<div class="overview">
<p>Steel is a managed browser API platform that lets developers control fleets of cloud-hosted browsers through a simple REST API. It handles browser infrastructure, session management, proxy rotation, and CAPTCHA solving, allowing teams to focus on building automation logic rather than managing infrastructure. The platform provides Playwright and Puppeteer-compatible APIs with built-in stealth features for production web scraping and automation.</p>
</div>
