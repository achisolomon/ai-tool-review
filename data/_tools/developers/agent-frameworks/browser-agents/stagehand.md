## Overview

<div class="overview">
<p>Stagehand is an open-source SDK that combines AI with Playwright to create resilient, production-ready browser agents. Built by Browserbase, it allows developers to control browsers using natural language while maintaining the reliability needed for production environments. The framework intelligently handles dynamic web content, works with any LLM provider, and provides built-in observability for debugging complex automation workflows.</p>
</div>
