## Overview

<div class="overview">
<p>Firecrawl is an API service by Mendable that turns entire websites into clean, LLM-ready markdown or structured data. Unlike traditional scrapers that return raw HTML, Firecrawl handles JavaScript rendering, bypasses anti-bot measures, and outputs formatted content perfect for AI ingestion. It offers three core modes: Scrape (single page), Crawl (entire site), and Map (sitemap discovery). With built-in support for extracting structured data via schemas, it's become the go-to solution for building AI agents that need real-time web data.</p>
</div>
