## Overview

<div class="overview">
<p>Total Recall provides persistent memory for AI agents, enabling them to retain context across sessions rather than starting fresh each conversation. The system captures narrative, decision, and pattern memories, then surfaces relevant context automatically or on-demand without bloating the active prompt. It uses local-first retrieval with zero LLM calls at search time, achieving deterministic performance.</p>
</div>
