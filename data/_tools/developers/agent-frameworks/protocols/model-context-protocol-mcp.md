## Overview

<div class="overview">
<p>Model Context Protocol (MCP) is an open-source standard developed by Anthropic that provides a universal way to connect AI applications to external systems. Like a USB-C port for AI, MCP standardizes how AI assistants access data sources (files, databases), tools (search engines, calculators), and workflows (specialized prompts). The protocol is already supported by major AI platforms including Claude, ChatGPT, VS Code Copilot, Cursor, and many others, creating a growing ecosystem of interoperable AI integrations.</p>
</div>
