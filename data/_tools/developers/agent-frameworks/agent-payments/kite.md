## Overview

<div class="overview">
<p>Kite is the payments infrastructure layer for the agent economy, launched on mainnet in April 2026. It provides AI agents with programmable, secure wallets to hold funds and make autonomous purchases while users retain control over spending limits and authorized destinations. The platform combines three layers: Kite Chain (native settlement), Kite Agent Passport (identity and wallet), and an Agent Interface layer. Kite positions itself as a unified hub for major payment protocol standards including x402, Google's AP2 protocol, Stripe's Machine Payment Protocol (MPP), and Anthropic's Model Context Protocol (MCP).</p>
</div>
