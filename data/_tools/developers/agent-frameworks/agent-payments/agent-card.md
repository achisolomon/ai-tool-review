## Overview

<div class="overview">
<p>Agent Card provides virtual debit cards designed specifically for AI agents, enabling autonomous purchases with built-in spending controls and real-time transaction monitoring. As part of the emerging agent payments infrastructure, Agent Card bridges traditional payment rails (Visa network) with AI agent workflows. Users can set spending limits, restrict merchant categories, and receive notifications for all agent transactions, maintaining oversight while enabling automation.</p>
</div>
