## Overview

<div class="overview">
<p>Sponge is financial infrastructure for the agent economy, enabling AI agents to hold and disburse funds without human intervention. Founded by ex-Stripe tech leads who built Stripe's stablecoin financial accounts and core money movement systems, Sponge provides wallets, payment gateways, and virtual cards for autonomous agents. Users fund their Sponge Wallet once, and agents autonomously use those funds to pay for services. Businesses can use Sponge Gateway to sell directly to agents without requiring human credit card entry or API key generation.</p>
</div>
