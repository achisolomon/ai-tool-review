## Overview

<div class="overview">
<p>Paragon is an embedded integration infrastructure platform designed for engineering teams building native product integrations. It provides a comprehensive toolkit including pre-built connectors, visual workflow builder, embedded UI components, and managed authentication to help SaaS companies ship customer-facing integrations 70% faster. Unlike general API platforms, Paragon focuses specifically on embedding integrations directly into products with white-labeled UI components, making it ideal for teams that want their integrations to feel native to their application rather than a separate tool.</p>
</div>
