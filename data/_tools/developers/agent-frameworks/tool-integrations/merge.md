## Overview

<div class="overview">
<p>Merge is a unified API platform that provides a single integration point to access 200+ B2B software applications across six major categories: HRIS, ATS (Applicant Tracking), CRM, Accounting, Ticketing, and File Storage. Instead of building and maintaining hundreds of individual API integrations, developers can use Merge's normalized data models to access customer data from platforms like Salesforce, Workday, QuickBooks, and more. The platform handles authentication, rate limiting, webhooks, and data normalization, making it ideal for AI agents and SaaS products requiring B2B data access.</p>
</div>
