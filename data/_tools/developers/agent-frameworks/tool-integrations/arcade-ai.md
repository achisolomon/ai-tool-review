## Overview

<div class="overview">
<p>Arcade AI is an MCP-native runtime platform designed specifically for production AI agents. It provides enterprise-grade secure authorization, reliable tool execution, and comprehensive governance capabilities. Built on the Model Context Protocol standard, Arcade simplifies the deployment of AI agents by handling authentication, rate limiting, error handling, and compliance requirements out of the box. The platform enables developers to ship AI agents faster with pre-built integrations and managed infrastructure.</p>
</div>
