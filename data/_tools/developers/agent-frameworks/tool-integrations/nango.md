## Overview

<div class="overview">
<p>Nango is an open-source integration platform that enables products and AI agents to connect with 800+ APIs through a unified interface. Built with a code-first approach, Nango provides pre-built OAuth flows, webhook handling, automatic token refresh, and built-in sync capabilities. Unlike low-code integration platforms, Nango is designed for developers who want full control over their integrations while avoiding the complexity of managing authentication, rate limiting, and API quirks across hundreds of services. The platform can be self-hosted or used as a managed cloud service.</p>
</div>
