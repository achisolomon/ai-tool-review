## Overview

<div class="overview">
<p>Pipedream Connect is a comprehensive developer toolkit that provides access to 2,700+ pre-built API integrations for building applications and AI agents. It combines a serverless execution environment with production-ready authentication, webhook handling, and data transformation capabilities. Unlike traditional integration platforms, Pipedream is designed with a code-first philosophy, allowing developers to write custom Node.js code while leveraging pre-built actions and triggers. The platform handles infrastructure, scaling, and monitoring automatically, making it ideal for rapidly deploying AI agents that need to interact with multiple services.</p>
</div>
