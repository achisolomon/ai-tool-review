## Overview

<div class="overview">
<p>AWS Bedrock AgentCore is Amazon's production-ready platform for deploying and managing AI agent fleets at enterprise scale. It provides secure agent identity management, framework-agnostic orchestration, and built-in compliance controls. The platform integrates with AWS Bedrock's foundation models while supporting any agent framework, offering centralized governance, observability, and access control for multi-agent systems across cloud and on-premises environments.</p>
</div>
