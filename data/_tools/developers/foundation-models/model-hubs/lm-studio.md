## Overview

<div class="overview">
<p>LM Studio is a free desktop application for running large language models locally on your computer with GPU acceleration. It features an intuitive interface for downloading models from Hugging Face, a built-in chat UI, and an OpenAI-compatible local server, supporting models like Llama, Mistral, Gemma, and Qwen for completely private, offline AI interactions.</p>
