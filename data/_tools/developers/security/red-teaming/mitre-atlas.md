MITRE ATLAS (Adversarial Threat Landscape for Artificial-Intelligence Systems) is a knowledge base of adversary tactics and techniques specific to AI/ML systems, following the ATT&CK framework structure.

## Key Features

- Adversary tactics and techniques (ATT&CK matrix style)
- AI/ML-specific threat modeling framework
- Documented real-world attack case studies
- Community contributions and updates
- Enterprise reference for security assessments

## Pricing

- Free: Open framework accessible to all organizations

- Regularly updated with emerging AI adversary techniques and tactics based on real-world incidents
