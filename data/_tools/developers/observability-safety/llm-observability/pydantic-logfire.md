## Overview

<div class="overview">
<p>Pydantic Logfire is an AI observability platform built by the creators of Pydantic, designed for production LLM and agent systems. Unlike tools that focus solely on LLM calls, Logfire provides end-to-end visibility across entire applications—capturing database queries, API requests, business logic, and AI components in unified traces. Built natively on OpenTelemetry, it features real-time LLM cost tracking, a SQL query interface for data analysis, live span viewing, and an integrated evaluation framework (Pydantic Evals). It supports Python, JavaScript/TypeScript, and Rust SDKs.</p>
</div>
