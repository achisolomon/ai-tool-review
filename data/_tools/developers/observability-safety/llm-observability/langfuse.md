## Overview

<div class="overview">
<p>Langfuse is an open source LLM engineering platform that provides comprehensive observability, tracing, and evaluation capabilities for AI applications. Built with a modular architecture, it offers production-grade tracing for complex LLM chains and agents, automated evaluations, prompt management with versioning, and cost tracking across providers. Langfuse was acquired by ClickHouse in 2025, bringing enterprise-scale data infrastructure to LLM observability. It integrates with all major frameworks including LangChain, LlamaIndex, OpenAI SDK, and supports self-hosting for data sovereignty requirements.</p>
</div>
