## Overview

<div class="overview">
<p>AgentOps is an observability platform built around AI agent sessions. After adding its SDK (two lines of Python), every agent run is recorded as a session you can replay step by step: the LLM calls, tool calls, errors and handoffs between agents, along with token usage and cost. That makes it easier to see where a multi-step agent went wrong, how much a run cost, and whether a change made things better or worse.</p>
<p>The SDK is open source under the MIT license and integrates natively with agent frameworks such as CrewAI, AutoGen/AG2, the OpenAI Agents SDK, LangChain and LlamaIndex, plus most major model providers. The hosted dashboard has a free tier, a Pro plan and an enterprise plan with self-hosting and compliance options.</p>
</div>
