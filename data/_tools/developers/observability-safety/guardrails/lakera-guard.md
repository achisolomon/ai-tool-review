## Overview

<div class="overview">
<p>Lakera Guard is an AI security API that protects LLM applications against prompt injection, jailbreaks, and data leakage in real time. Acquired by Cisco in May 2025, the platform delivers 98%+ detection rates with sub-50ms latency across 100+ languages. Lakera's threat intelligence is powered by Gandalf, an adversarial AI game that has generated 80M+ attack prompts from over 1 million players. The API evaluates both inputs and outputs, returning allow/block/sanitize decisions that integrate with any LLM provider. The Zurich-based research team continues maintaining Guard's detection models under Cisco AI Defense.</p>
</div>
