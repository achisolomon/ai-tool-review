## Overview

<div class="overview">
<p>Prompt Security is a developer-first platform focused on securing LLM-powered applications. It provides runtime protection against prompt injection, sensitive data leaks, and unauthorized content generation. The platform acts as a security layer over existing prompt infrastructure without requiring code rewrites, supporting OpenAI, Claude, Azure AI, and other LLM providers via API integration. Prompt Security also offers "Prompt Fuzzer," an open-source GenAI vulnerability assessment tool, and features a transparent risk scoring system with parameter breakdowns for evaluating AI tools and MCP servers.</p>
</div>
