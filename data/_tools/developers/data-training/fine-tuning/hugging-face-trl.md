## Overview

<div class="overview">
<p>TRL (Transformer Reinforcement Learning) is Hugging Face's library for fine-tuning language models using reinforcement learning methods including PPO, DPO, GRPO, and reward modeling. It integrates seamlessly with the Transformers ecosystem and Accelerate for distributed training.</p>
