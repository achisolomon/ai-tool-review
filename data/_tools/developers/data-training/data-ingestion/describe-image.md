## Overview

<div class="overview">
<p>Describe Image is a visual analysis platform built on Anthropic's Claude Agent SDK, using Claude's vision capabilities to convert images and videos into text. It offers more than 11 output modes: alt text generation, OCR in 32 languages, SEO-oriented descriptions, product listings formatted for Amazon, Shopify, and Etsy, reverse-engineered prompts for image generators like Midjourney, DALL-E, Stable Diffusion, and Flux, social media captions, chart and data analysis, video scene summaries with timestamps, and UI screenshot to code conversion. Users upload an image or video and select the output mode they need rather than writing a prompt.</p>
</div>
