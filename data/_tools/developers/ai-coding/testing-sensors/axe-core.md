## Overview

<div class="overview">
<p>axe-core is Deque's open-source accessibility testing engine for websites and HTML-based user interfaces. Designed for speed, security, and accuracy, it returns zero false positives (bugs notwithstanding) and integrates seamlessly with any existing test environment. The library works across all modern browsers and frameworks, enabling automated accessibility testing alongside regular functional testing without requiring specialized knowledge of WCAG guidelines.</p>
</div>
