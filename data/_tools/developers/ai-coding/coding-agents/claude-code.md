## Overview

<div class="overview">
<p>Claude Code is Anthropic's agentic coding assistant that runs in your terminal and understands your entire codebase. Unlike IDE plugins that work file-by-file, Claude Code can read, search, and edit multiple files simultaneously while executing shell commands autonomously. It excels at complex refactoring, debugging across codebases, and implementing features that touch many files. The 1M token context window means it can hold your entire project in memory.</p>
</div>
