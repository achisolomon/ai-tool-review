## Overview

<div class="overview">
<p>Cline (formerly Claude Dev) is an open-source autonomous AI coding agent that runs directly in VS Code. Unlike simple autocomplete tools, Cline can create and edit files, run terminal commands, browse the web, and execute multi-step coding tasks autonomously. It works with any LLM API including Claude, GPT-4, Gemini, DeepSeek, and local models via Ollama or LM Studio. The extension is completely free with you paying only for API usage, making it a budget-friendly alternative to subscription-based coding assistants.</p>
</div>
