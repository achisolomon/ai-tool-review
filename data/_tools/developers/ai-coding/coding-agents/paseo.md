## Overview

<div class="overview">
<p>Paseo is an agentic development environment that orchestrates multiple AI coding agents, Claude Code, Codex, GitHub Copilot, OpenCode, and Pi, from one interface across desktop, mobile (iOS/Android), web, and CLI clients. Agents run on your own machine with your existing dev environment, tools, and configs, with git-worktree-based isolation for separate agent branches. It adds voice control for hands-free task dictation and a plugin system (TypeScript via npm, Git, or local directory) for extending the workflow. The project is maintained independently by a single developer who has turned down investor funding to keep it neutral and vendor-independent.</p>
</div>
