## Overview

<div class="overview">
<p>Conductor is a macOS app, built by Melty Labs, for running parallel Claude Code, Codex, and Cursor agents in isolated workspaces. Each workspace is its own git worktree, so agents don't collide while working on the same repo at the same time. Conductor gives you a single control surface to see at a glance what every agent is doing, then review diffs and merge their changes. A Cloud tier adds remote workspaces (on Vercel sandboxes) and a mobile app for monitoring agents away from your desk.</p>
</div>

## The Verdict

<div class="verdict">
  <h3>Who Should Use Conductor?</h3>
  <div class="verdict-grid">
    <div class="verdict-section">
      <h4>Best For</h4>
      <ul>
        <li>Mac-based developers running Claude Code, Codex, or Cursor at scale</li>
        <li>Teams parallelizing multiple features or bug fixes across the same codebase</li>
        <li>Engineers who want to review and merge agent diffs from one place instead of juggling terminal tabs</li>
        <li>Teams wanting mobile oversight of long-running cloud agents</li>
      </ul>
    </div>
    <div class="verdict-section not-for">
      <h4>Not Ideal For</h4>
      <ul>
        <li>Windows or Linux developers — Conductor is Mac-only</li>
        <li>Projects that aren't on GitHub-compatible git repos</li>
        <li>Teams that want self-hosted cloud workspaces today</li>
        <li>Solo, single-task workflows (use the underlying agent directly)</li>
      </ul>
    </div>
  </div>

      <li>Single UI to monitor, diff-review, and merge changes from multiple agents</li>

      <li>Mobile app for checking in on cloud workspaces remotely</li>

  <div class="cons-list">
    <h3>Watch Out For</h3>
    <ul>
      <li>Mac-only — no native Windows or Linux client</li>

      <li>No self-hosted option yet; Enterprise customers can only inquire about future support</li>
      <li>Underlying agent/API costs (Claude Code, Codex, Cursor) are separate from Conductor's own pricing</li>
