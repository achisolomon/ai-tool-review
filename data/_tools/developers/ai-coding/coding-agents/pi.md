## Overview

<div class="overview">
<p>Pi is a minimal agent harness designed for AI coding workflows, emphasizing adaptability over rigid structure. Rather than imposing opinions, Pi lets developers customize through extensions, skills, and prompt templates. The toolkit includes a unified multi-provider LLM API (@earendil-works/pi-ai), an agent runtime with tool calling and state management (@earendil-works/pi-agent-core), and an interactive coding agent CLI (@earendil-works/pi-coding-agent). Pi is notable for offering a credible "self-hosted model, code never leaves the boundary" path out of the box, driving interest from regulated industries.</p>
</div>

  <div class="verdict-grid">

      <h4>Best For</h4>
      <ul>
        <li>Developers wanting a lightweight, unopinionated agent harness</li>

        <li>Power users who want to extend and customize their workflow</li>
        <li>Developers who prefer TypeScript-based tooling</li>
        <li>Those needing mid-session model switching across providers</li>

    <div class="verdict-section not-for">
      <h4>Not Ideal For</h4>

        <li>Non-technical users needing guided workflows</li>
        <li>Teams requiring built-in plan mode or to-do tracking</li>
        <li>Those preferring opinionated, all-in-one solutions</li>
      </ul>

<div class="pros-cons">
  <div class="pros-list">
    <h3>What's Great</h3>
    <ul>
      <li>Minimal footprint — intentionally excludes bloat</li>
      <li>15+ LLM providers with mid-session switching</li>
      <li>Tree-structured sessions with HTML/gist export</li>
      <li>Self-hosted model path for data-sensitive environments</li>
      <li>TypeScript extensions for custom commands and tools</li>
      <li>AGENTS.md and SYSTEM.md for project-level instructions</li>
      <li>Strong community adoption</li>
    </ul>
    <div class="source"><a href="https://pi.dev" target="_blank">Official Site</a> · <a href="https://github.com/earendil-works/pi" target="_blank">GitHub</a></div>
  </div>
  <div class="cons-list">
    <h3>Watch Out For</h3>
    <ul>
      <li>No built-in MCP integration (requires extension)</li>
      <li>No built-in sub-agents, plan mode, or to-do tracking</li>
      <li>No permission popups — less guardrails by default</li>
      <li>Requires TypeScript knowledge for deep customization</li>
      <li>Minimalist philosophy may require more setup</li>
    </ul>
