## Overview

<div class="overview">
<p>Roo Code (Roomote) is an AI-powered engineering agent that handles operational engineering work directly from Slack. It tackles bug reports, support escalations, QA regressions, and repository questions autonomously, delivering verified PRs or investigations. Built for teams tired of senior engineers getting pulled off roadmap work for interrupt-driven tasks, Roo Code integrates with your repos, docs, tickets, and logs to provide context-aware solutions that are tested before human review.</p>
</div>
