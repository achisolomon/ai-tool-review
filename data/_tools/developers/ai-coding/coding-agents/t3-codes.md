## Overview

<div class="overview">
<p>T3 Code is an open-source control plane that consolidates multiple AI coding agents, Claude Code, Codex, Antigravity, OpenCode, Cursor, and Grok, into a single unified workspace. It follows a "bring your own subscription" model with no token reselling: each agent thread writes to its own branch, with inline diff review, one-click PR generation with auto-written titles and bodies, and draft/stack/amend PR workflows. It runs across macOS, Windows, Linux, iOS, and Android, making it usable as a remote development front-end for agent work in progress.</p>
</div>
