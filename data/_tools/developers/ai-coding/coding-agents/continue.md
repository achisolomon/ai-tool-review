## Overview

<div class="overview">
<p>Continue is the leading open-source AI code assistant that brings the power of any LLM directly into VS Code and JetBrains IDEs. Unlike proprietary alternatives, Continue gives developers complete control over which models they use—from Claude and GPT-4 to local models via Ollama. It offers autocomplete, chat, inline editing, and codebase-aware context while keeping your code private and your costs under control. The Apache 2.0 license means you can self-host, customize, and extend it freely.</p>
</div>
