## Overview

<div class="overview">
<p>Skills-IL (ספריית הסקילס הישראלית) is a Hebrew-first directory of ready-to-install skills and MCP servers for AI agents, built around Israeli needs: Hebrew document and content generation, RTL web design, Israeli tax and accounting automation, and government-services bureaucracy. Every listed skill is open-source and goes through a three-layer review (static code analysis, third-party dependency scanning, human review) before publication. Skills install into Claude, ChatGPT, Cursor, GitHub Copilot, Windsurf, and other agents that support the skill/MCP format.</p>
</div>
