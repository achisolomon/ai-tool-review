## Overview

<div class="overview">
<p>Sourcery is an AI-powered code quality tool specifically designed for Python developers. It provides instant refactoring suggestions, catches code smells, and enforces best practices directly in your IDE. Sourcery combines static analysis with machine learning to understand code context and suggest improvements that go beyond simple linting. It's built for teams who want to maintain high-quality Python codebases while moving fast with AI-generated code.</p>
</div>
