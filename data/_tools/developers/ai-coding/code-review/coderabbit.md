## Overview

<div class="overview">
<p>CodeRabbit is an AI-powered code review assistant that automatically analyzes pull requests and provides contextual, line-by-line feedback. Unlike static analysis tools that only catch syntax errors, CodeRabbit understands code semantics, business logic, and project context to deliver meaningful suggestions. It integrates directly with GitHub, GitLab, and Azure DevOps, posting reviews as native comments that developers can interact with, ask follow-up questions, and request re-reviews after changes.</p>
</div>

## How It Works

<div class="info-grid">
  <div class="info-card">
    <h4>1. Install & Connect</h4>
    <p>Add CodeRabbit GitHub App or GitLab integration to your repositories. Takes less than 2 minutes.</p>
  </div>
  <div class="info-card">
    <h4>2. Open a PR</h4>
    <p>When you create or update a pull request, CodeRabbit automatically analyzes the changes.</p>
  </div>
  <div class="info-card">
    <h4>3. Review Comments</h4>
    <p>AI posts line-by-line suggestions as native PR comments. Reply to ask questions or request clarification.</p>
  </div>
  <div class="info-card">
    <h4>4. Iterate & Merge</h4>
    <p>Address feedback, push changes. CodeRabbit re-reviews and confirms fixes. Human reviewers can focus on architecture.</p>
  </div>
</div>
