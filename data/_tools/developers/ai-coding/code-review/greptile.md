## Overview

<div class="overview">
<p>Greptile is an AI-powered code review platform that provides comprehensive codebase understanding for automated PR reviews. It analyzes entire repositories to catch bugs, security issues, and code quality problems before they reach production. With contextual awareness across your full codebase, Greptile delivers intelligent reviews that go beyond simple linting to understand architectural patterns and business logic.</p>
</div>
