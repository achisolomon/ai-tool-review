## Overview

<div class="overview">
<p>CodeScene is an AI-powered code health platform that uses behavioral code analysis to identify technical debt, code quality issues, and organizational bottlenecks based on how your codebase actually evolves over time. Unlike traditional static analysis tools that only look at snapshots, CodeScene analyzes Git history to understand change patterns, hotspots, and team dynamics. The platform translates code health improvements into business impact metrics, helping engineering leaders prioritize refactoring work that matters. With its CodeHealth MCP integration, CodeScene guides AI coding agents toward maintainable outcomes, ensuring that AI-generated code meets quality standards and doesn't introduce new technical debt.</p>
</div>
