## Overview

<div class="overview">
<p>Git AI is an open-source command-line tool that brings AI-powered assistance to your Git workflow. It automates repetitive tasks like writing commit messages, generating pull request descriptions, and performing intelligent code reviews. Built for developers who want to streamline their Git operations without leaving the terminal, Git AI integrates seamlessly with existing workflows and supports multiple AI providers.</p>
</div>
