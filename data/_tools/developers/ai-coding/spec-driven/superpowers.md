## Overview

<div class="overview">
<p>Superpowers is an agentic skills framework and software development methodology designed for reliable AI-assisted coding. It provides structured, reusable skills for common development workflows including test-driven development, systematic debugging, plan writing/execution, code review, and verification gates. Each skill codifies best practices into repeatable procedures that AI agents can invoke, ensuring consistent quality and preventing common pitfalls like false completion claims or skipped verification steps.</p>
</div>
