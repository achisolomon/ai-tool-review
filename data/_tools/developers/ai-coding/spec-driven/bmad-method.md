## Overview

<div class="overview">
<p>BMAD-METHOD (Breakthrough Method for Agile AI-Driven Development) is a spec-driven development methodology designed for human-AI collaboration. It features scale-adaptive planning that automatically adjusts complexity based on project size, AI-powered intelligent help through the bmad-help skill, and structured artifacts for proposals, specs, and tasks. The framework ensures alignment between developers and AI agents before code is written, maintaining organized workflows with dedicated folders per feature or change.</p>
</div>
