## Overview

<div class="overview">
<p>Zed is a next-generation code editor built from the ground up in Rust for maximum performance and responsiveness. Created by the original authors of Atom and Tree-sitter, Zed combines lightning-fast speed with innovative multiplayer collaboration features that allow multiple developers to edit the same codebase in real-time. The editor includes built-in AI assistance powered by multiple language models, intelligent code completion, and seamless integration with modern development workflows. Zed's native architecture delivers instant startup times and smooth performance even on large codebases, while its collaborative features enable true pair programming without the lag.</p>
</div>
