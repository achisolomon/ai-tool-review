## Overview

<div class="overview">
<p>Cursor is an AI-first code editor built on VS Code that transforms how developers write code. Unlike traditional IDEs with AI bolted on, Cursor was designed from the ground up for AI pair programming. Its signature features include Tab for intelligent multi-line autocomplete that predicts your next edit, Chat for codebase-aware conversations, and Composer for coordinated multi-file edits. The editor understands your entire project context and can make sweeping changes across files while maintaining consistency.</p>
</div>
