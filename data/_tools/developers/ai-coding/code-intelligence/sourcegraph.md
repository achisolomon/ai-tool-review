## Overview

<div class="overview">
<p>Sourcegraph is an enterprise code intelligence platform that enables teams to take control of complex codebases through AI-powered search and deep navigation. The platform provides complete context for understanding, overseeing, and evolving large codebases—empowering both human developers and AI coding agents. With features like Deep Search (natural language AI search with cited answers), deterministic Code Search, MCP server integration, batch changes, and code insights, Sourcegraph serves as the context layer that makes coding agents more accurate and efficient at scale.</p>
</div>
