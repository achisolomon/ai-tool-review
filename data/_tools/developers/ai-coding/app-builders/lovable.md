## Overview

<div class="overview">
<p>Lovable (formerly GPT Engineer) is an AI-powered full-stack application builder that lets you create complete web applications through natural language conversations. Unlike UI-only generators, Lovable handles the entire stack: React frontend with Tailwind CSS, Supabase backend for authentication and database, and one-click deployment. You describe your app idea, iterate through chat, and Lovable generates production-ready code that syncs to GitHub. It's designed for founders, product managers, and developers who want to go from idea to deployed app without wrestling with infrastructure.</p>
</div>
