## Overview

<div class="overview">
<p>Shetef (שטף) is a Hebrew voice dictation tool for Windows built by Israeli AI developer Aviel Sela. Press Ctrl+Space in any application — Word, WhatsApp, email, CRM, browsers — speak in Hebrew, and text appears at the cursor. All transcription runs locally on the user's device; no audio is uploaded or stored. The tool handles mixed Hebrew-English input and professional terminology, and includes a personal dictionary for names and domain-specific terms. An organizational version is available for businesses that need managed deployment and centralized term dictionaries.</p>
</div>
