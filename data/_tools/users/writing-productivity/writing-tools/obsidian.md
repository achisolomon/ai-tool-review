Local-first markdown note-taking with bidirectional linking and AI plugins

## Overview
Obsidian is a privacy-first, local-first markdown note-taking application with powerful linking capabilities and an extensive plugin ecosystem. Originally built for knowledge workers, it has become a popular base for AI integrations through community plugins that connect to Claude, GPT-4, and local models. Many users employ it as a long-term memory system for AI interactions.

## Key Features

- Local-first markdown files with full ownership and privacy
- Bidirectional linking and knowledge graph visualization
- Extensive plugin ecosystem (1000+ community plugins)
- AI integrations via plugins (Obsidian Copilot, Smart Connections, etc.)
- Canvas feature for visual note organization
- Offline-first with optional sync
- Customizable themes and appearance
- Backlinks and reference management
