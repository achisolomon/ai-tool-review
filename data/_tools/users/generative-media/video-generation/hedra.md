## Overview

<div class="overview">
<p>Hedra is an AI video generation startup specializing in creating expressive talking head and character performance videos. Its flagship Character-1 foundation model generates lifelike lip-synced videos from just an audio file and a character image. Unlike traditional avatar platforms that animate pre-built 3D models, Hedra uses generative AI to create organic, expressive performances with natural head movements, facial expressions, and emotional nuance. The platform is popular among content creators, marketers, and developers building AI-powered video applications, offering both a web interface and API access.</p>
</div>
