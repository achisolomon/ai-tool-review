## Overview

<div class="overview">
<p>AI Image Cleaner is a web-based tool for removing unwanted elements from photos, including people, objects, text, and watermarks. Users upload an image and paint over the item they want gone; the tool then uses AI inpainting, employing techniques inspired by LaMa research, to reconstruct the background underneath. It runs in the browser with no local install.</p>
</div>
