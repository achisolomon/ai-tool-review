## Overview

<div class="overview">
<p>AI Image Cleanup Tool removes unwanted text from photos and screenshots. It uses machine learning to detect text regions automatically, then applies inpainting to reconstruct the background that was underneath. Users can accept the auto-detected selection or manually refine it before processing. The tool supports JPG, PNG, WEBP, and screenshot files, and shows a before/after comparison slider on the result. It runs entirely in the browser, with no software install required. The same site also links to related tools for watermark removal, logo removal, object removal, and background removal.</p>
</div>
