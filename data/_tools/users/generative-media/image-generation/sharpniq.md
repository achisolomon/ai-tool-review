## Overview

<div class="overview">
<p>Sharpniq removes blur from images using either on-device browser processing or cloud-based AI, sharpening detail and improving clarity. The browser mode runs fully free with no sign-in, processing images up to 4MP locally in the browser. The cloud mode handles larger files up to 12MP and uses a credit system. It's built to handle several distinct blur types: soft focus, motion blur, compression artifacts, and low-light camera shake. Supported formats include JPG, PNG, WebP, AVIF, static GIF, HEIC/HEIF, TIFF, BMP, and SVG. The cloud option auto-deletes uploaded files after 24 hours, and the local browser mode keeps processing on-device rather than uploading images at all.</p>
</div>
