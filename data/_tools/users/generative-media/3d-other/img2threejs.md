## Overview

<div class="overview">
<p>img2threejs.org is a hosted service that turns a reference image into a textured 3D model built for the web. Its main route, Native Mesh, uses AI models to generate a textured GLB asset; a second route, Editable Procedural Draft, produces a code-first Three.js scene you can edit in source. Each download comes as a package: the GLB with levels of detail, a React Three Fiber component, a vanilla Three.js loader, a materials file, a preview image and a README with performance measurements. It is aimed at web developers and designers who want a 3D object on a site without modeling it by hand. It is a separate product from the open-source img2threejs agent skill on GitHub.</p>
</div>
