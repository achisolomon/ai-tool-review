## Overview

<div class="overview">
<p>Coze is ByteDance's AI agent platform that enables users to build and deploy sophisticated chatbots without coding. The platform provides a visual workflow builder with drag-and-drop components, access to premium models like GPT-4o on the free tier, and a plugin ecosystem of 400+ integrations including Google search, weather APIs, and DALL-E 3 image generation. Coze supports multi-agent workflows where specialized bots can hand off tasks to each other, and offers one-click deployment to platforms like Discord, Slack, Telegram, and LINE. With Coze 3.0 (2026), the platform now supports multi-user, multi-agent collaboration and industry-specific skill packs for finance, healthcare, law, and content creation.</p>
</div>
