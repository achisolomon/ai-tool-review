## Overview

<div class="overview">
<p>BuildShip is an AI-powered visual backend and workflow builder created by Rowy Inc. that enables users to create APIs, scheduled jobs, and automated workflows using natural language descriptions or a drag-and-drop interface. Unlike traditional no-code tools, BuildShip offers full code access with the ability to export production-ready JavaScript and deploy to your own infrastructure (AWS, GCP, Azure, Vercel) or use their managed cloud. The platform integrates with major AI providers including OpenAI, Claude, and Stable Diffusion, and supports version control via GitHub. Notable customers include the World Health Organization, Deriv, and 99 Hunters.</p>
</div>
