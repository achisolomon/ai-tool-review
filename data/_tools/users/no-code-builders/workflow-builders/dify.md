## Overview

<div class="overview">
<p>Dify is an open-source LLM app development platform that combines AI workflow building, RAG pipelines, agent capabilities, model management, and observability features in a unified visual interface. Created by LangGenius and launched in March 2023, it enables teams to rapidly go from prototype to production without extensive backend development. The platform supports 300+ LLM models including OpenAI, Anthropic, Google, and local models, with a drag-and-drop workflow builder featuring conditional logic and branching nodes. With native MCP (Model Context Protocol) integration and a marketplace of 800+ plugins, Dify serves organizations across 190+ countries from startups to Fortune 500 companies. In March 2026, Dify secured $30M in Series Pre-A funding.</p>
</div>

<div class="pros-cons">
  <div class="pros-list">
    <h3>What's Great</h3>
    <ul>
      <li>Best debugging experience with execution time, I/O values, and token usage per node</li>
      <li>Production-ready RAG pipeline handles chunking, embedding, indexing automatically</li>
      <li>Every workflow exposes as API endpoint with auth and rate limiting built-in</li>
      <li>300+ LLM support eliminates vendor lock-in concerns</li>
      <li>Open-source foundation with self-hosting removes all usage caps</li>
      <li>Native MCP integration with 800+ plugin marketplace</li>
      <li>Strong customization and private deployment options</li>
      <li>Generous free tier to get started</li>
    </ul>

  <div class="cons-list">
    <h3>Watch Out For</h3>
    <ul>
      <li>Steep learning curve for newcomers to AI development</li>
      <li>Self-hosting requires IT support and DevOps expertise</li>
      <li>Heaviest resource requirements (4GB RAM minimum)</li>
      <li>Abstractions don't map to LangChain - migration means rewriting</li>
      <li>Cloud version has variable size limits and missing features vs self-hosted</li>

      <li>Customer support sometimes receives criticism for generic responses</li>
