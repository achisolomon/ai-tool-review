## Overview

<div class="overview">
<p>n8n is a workflow automation platform that sits between no-code tools like Zapier and writing everything in code. You build workflows visually from 500+ integration nodes, drop into JavaScript or Python whenever you need to, and inspect the data at every step. AI is now central: n8n has nodes for building AI agents with memory and tools, RAG pipelines, human-in-the-loop approvals and MCP, so teams use it to put LLMs into real business processes.</p>
<p>n8n is "fair-code": the source is public under the Sustainable Use License and you can self-host it for free, including fully air-gapped, or use n8n Cloud. The Berlin company raised a $180M Series C at a $2.5B valuation in October 2025, and SAP invested in May 2026 at a $5.2B valuation, with a deal to embed n8n in SAP's Joule Studio.</p>
</div>
