## Overview

<div class="overview">
<p>Mistral Le Chat (recently rebranded as Mistral Vibe) is an AI chat assistant and coding agent built by Mistral AI, Europe's most valuable AI company valued at $13.7B. Designed for both work and code, it combines conversational AI with coding automation in a single platform. Powered by Mistral Large 3, featuring 675B total parameters with 41B active through Mixture-of-Experts architecture, Le Chat delivers up to 1,000 words per second while maintaining GDPR compliance with EU-based data processing. The platform integrates with 100+ tools including email, calendar, Slack, GitHub, and Jira, and supports over 100 languages including regional dialects.</p>
</div>
