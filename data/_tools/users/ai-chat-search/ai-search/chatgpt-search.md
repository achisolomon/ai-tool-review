## Overview

<div class="overview">
<p>ChatGPT Search is OpenAI's real-time web search capability integrated directly into ChatGPT. Rather than relying solely on training data with a knowledge cutoff, it enables live web browsing to answer questions about current events, recent developments, and time-sensitive topics. Powered by Bing's index for real-time web retrieval, responses include inline citations that users can hover over or click to view sources. The feature reduces hallucination rates from 47% to 9.6% when browsing is enabled—a 37-point improvement. ChatGPT Search is available across all tiers including Free (with ads in the US), Plus, Team, Enterprise, and Edu plans.</p>
</div>
