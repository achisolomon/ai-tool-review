## Overview

<div class="overview">
<p>Claude Artifacts enables creating interactive, visually polished slide presentations directly within the Claude chat interface. Unlike traditional AI slide tools, Claude generates self-contained HTML/CSS/JS or React-based presentations that render live in the chat. You can ask for reveal.js decks, animated Framer Motion slides, or custom React components with Tailwind CSS styling. The result is a working mini-website that you preview, iterate on, and export—all without leaving the conversation.</p>
</div>
