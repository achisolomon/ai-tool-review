Local-first markdown note-taking app with powerful linking and plugin ecosystem. Used as Claude memory app for long-term context through community plugins like Smart Connections and Obsidian Copilot.

## Key Features

- Local-first markdown files with full ownership
- Bidirectional linking and knowledge graph visualization
- Extensive plugin ecosystem (1000+ community plugins)
- AI integrations via plugins for Claude, GPT, and local models
- Canvas for visual note organization
